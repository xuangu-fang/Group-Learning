会议主题：扩散模型Back to Basics论文分享研讨会

会议摘要：本次会议陈力豪分享了基于流形假设的扩散模型新范式，探讨了直接预测干净图像（X-prediction）在高维生成任务中的优势，并明确了后续隐空间建模的研究方向。
---
一、论文核心思想与理论框架
陈力豪分享了论文《Back to Basics》的核心观点，即回归扩散模型去噪本质，通过直接预测干净图像（X-prediction）来规避高维噪声拟合难题。
1. 流形假设与预测目标重构
主流方法的局限性：指出当前 DDPM（预测噪声）和 Flow Matching（预测流速）等方法在高维流形上拟合噪声或流速存在本质困难，因为这些量本身处于高维空间。
低维流形优势：基于自然图像数据存在于低维流形的假设，提出直接预测干净图像（X-prediction）只需在低维流形上进行，相比预测高维噪声或流速更简单有效。
组合实验验证：论文通过九种预测目标与损失函数的组合实验，验证了“网络预测 X（干净图像）+ 损失函数使用 V（流速）”的组合效果最佳。
2. 极简架构设计与实验结论
Transformer 架构应用：将图像分块（Patch）作为 Token 输入 Transformer，构建了一个无需预训练、无分类器引导的极简生成框架。
高维生成有效性：在高维玩具实验（如 256 维 MLP 生成螺旋线）中，X-prediction 表现出色，而 Epsilon-prediction 和 V-prediction 失效，证明了低维拟合的有效性。
参数无关性：实验表明增加隐藏层单元对 X-prediction 效果提升有限，且引入瓶颈层（Bottleneck）反而有助于性能提升，进一步印证了低维流形假设。
二、技术细节与实验对比
会议详细讨论了论文中的具体技术实现及与其他方法的对比结果。
3. 关键技术细节
EDM 技巧对比：论文对比了 EDM（Exponential Moving Average）技巧，发现直接使用 X-prediction 效果优于 EDM 的加权策略，因为 EDM 本质上偏离了直接预测 X 的目标。
损失函数表现：在相同 Loss Function 下，X-prediction 的损失值显著低于 V-prediction，表明网络能更轻松地学习低维特征。
4. 扩展性与通用性
Transformer 通用改进兼容：该框架兼容 Transformer 的通用改进（如激活函数、归一化、位置编码等），且具备 Scaling Law 特性，即参数量增加能持续提升效果。
条件生成潜力：尽管架构极简，但支持插入分类器头进行条件生成，展示了良好的可扩展性。
三、深度研讨与工程落地
参会人员针对论文的底层逻辑及在现有项目中的适用性进行了深入探讨。
5. 架构与流形假设的深层逻辑
【提问人】方榯楷Shikai Fang：为什么 U-Net 架构直接预测 X 会失败，而 Transformer 架构却成功？
【回答人】方榯楷Shikai Fang：U-Net 的 Bottleneck 设计试图压缩输入，但噪声本身是高维满秩矩阵，不可压缩；而 Transformer 通过分块（Patch）处理，不强制压缩噪声，而是学习 Patch 间的关系，更适合处理高维噪声输入。
【提问人】张欣宇：既然论文强调简单 MLP 也能学习，为什么还要用 Transformer？
【回答人】陈力豪：MLP 实验用于验证理论可行性，后续图像生成任务采用了 Transformer 架构以处理 Patch 间的关系。
6. 现有项目适配性评估
【提问人】方榯楷Shikai Fang：目前项目数据已在隐空间（Latent Space）中，是否适用该论文方法？
【回答人】方榯楷Shikai Fang：由于隐空间本身已经过压缩，维度较低，该论文方法带来的提升可能有限，甚至不如继续使用 EDM 或 DDPM 混合策略。
【提问人】张欣宇：论文中提到在低分辨率（如 64x64）下所有方法都有效，高分辨率下才有差异，这是否意味着该方法对低分辨率任务帮助不大？
【回答人】陈力豪：是的，在低分辨率下噪声维度不高，传统方法也能学习；但在高分辨率（如 256x256）下，X-prediction 的优势才会凸显。
四、科研品味与后续规划
会议最后对论文的科研价值进行了总结，并制定了后续的研究方向。
7. 科研品味与论文价值
大道至简的科研品味：方榯楷高度评价了论文“从底层原理出发，用简单方法解决复杂问题”的科研思路，认为这是优秀科研工作的典范。
工程指导意义：论文的“九宫格”对比实验为工程选型提供了指导原则，即针对高维稀疏信号（如张量），若无法直接预测 X，应优先选择 V-prediction 或 EDM 策略。
8. 后续研究方向
显空间与隐空间之争：确立了“显空间（Pixel Space）建模”与“隐空间（Latent Space）建模”两条技术路线的对比研究计划。
JEPA 模型研究：指定陈力豪在下次分享中讲解杨立昆（Yann LeCun）团队的 JEPA 模型，重点探讨隐空间建模如何更好地表征世界。
